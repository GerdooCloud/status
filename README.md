# Gerdoo status monitor — retired

The public status page is hosted at https://gerdoocloudstatus.ir/.
The active Arvan Edge data feed is
https://gerdoo-status-monitor.waaldev-ch223.arvanedge.ir/status.json.

The GitHub monitoring workflow and its `status-data` branch were removed on
2026-10-28 after migration to Arvan Edge and an external cron scheduler.
The old GitHub Pages snapshot is no longer updated.

This repository retains the former public source and seed history for reference.
Application CI/CD remains in the private GerdooCloud/gerdoo repository.
